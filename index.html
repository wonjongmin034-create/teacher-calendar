구글 연결 설정 (처음 한 번)
  1. Google Cloud에서 프로젝트 만들기
  2. 'API 및 서비스 → 라이브러리'에서 Google Calendar API 사용 설정

  4. '사용자 인증 정보 → OAuth 클라이언트 ID(웹 애플리케이션)' 만들기. 승인된 JavaScript 원본에 추가
  5. 나온 클라이언트 ID를 위 칸에 붙여넣기
